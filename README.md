#Real Madrid Club Archive

A responsive, static website for exploring Real Madrid club information and La Liga season statistics. Visitors can compare team seasons, browse player statistics, search by player and position, and view club and legend profiles.

## Pages

•⁠  ⁠*Overview (⁠ index.html ⁠)* — Season results and key statistics, plus a visual introduction to the club.
•⁠  ⁠*First team (⁠ squad.html ⁠)* — Player appearances and goals for four La Liga seasons. Change seasons, search by player name, and filter by position.
•⁠  ⁠*Player lookup (⁠ player-lookup.html ⁠)* — Look up a player from the local archive and filter by position. The form also asks for a shirt number for validation, but that number is not used to find players.
•⁠  ⁠*Club profile (⁠ club.html ⁠)* — Club background, home ground, honours, and links to the rest of the archive.

## Run the website

No installation or build step is required. Open ⁠ index.html ⁠ in a modern web browser. The pages use local HTML, CSS, and JavaScript files, so the main features do not require a server or account.

## Project files

•⁠  ⁠⁠ index.html ⁠, ⁠ squad.html ⁠, ⁠ player-lookup.html ⁠, ⁠ club.html ⁠ — Website pages.
•⁠  ⁠⁠ style.css ⁠ — Layout, visual styling, and responsive navigation.
•⁠  ⁠⁠ script.js ⁠ — Local season and player data, season controls, filters, and lookup form behavior.

## Data and assets

Season and player records are stored in ⁠ script.js ⁠. The archive covers the 2022/23, 2023/24, 2024/25, and 2025/26 La Liga seasons; it does not include other competitions. Season statistics link to FotMob, while club and legend information links to Real Madrid's official website.

Some photos are hosted by Unsplash and the site’s fonts are loaded from Google Fonts. These external assets need an internet connection and may not appear offline; the locally stored pages and data remain available.
